# 🎬 TikTok AI Studio — Flow & Meta AI Auto Video Creator

ส่วนขยาย Chrome Extension (สร้างด้วย **Vite + React + Tailwind CSS**) สำหรับสร้างภาพและวิดีโอโปรโมทสินค้า TikTok Shop Showcase อัตโนมัติ โดยเชื่อมต่อกับ **Google Flow** และ **Meta AI** พร้อมระบบ AI Prompt Generator ด้วย **DeepSeek-V3 (`deepseek-chat`)** ในราคาประหยัดที่สุด และระบบนำคลิปขึ้น TikTok Studio เพื่อปักตะกร้าสินค้า

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ดึงสินค้าจาก TikTok Shop Showcase อัตโนมัติ**:
   - ดึงข้อมูลสินค้า (รูปปก, ชื่อสินค้า, ราคา, ชื่อร้าน) จาก API ทางการของ TikTok Showcase
   - รองรับการเลือกสินค้าเป็นรายชิ้น หรือให้ระบบหมุนเวียนสินค้าอัตโนมัติในแต่ละรอบ (Round-Robin)

2. **6 โหมดสไตล์การตลาด (Marketing Presets)**:
   - 📦 **โกดัง ลดล้างสต๊อก**: บรรยากาศโกดัง ป้ายราคาสีเหลืองตัวหนา กล่องพัสดุกองเรียงราย
   - 💥 **ลดแรง โกดังแตก**: บรรยากาศเร่งด่วน ป้ายแดงเหลือง ดึงดูดสายตากระตุ้นยอดขาย
   - 📱 **UGC สมจริง (รีวิวผู้ใช้จริง)**: คนไทยรีวิวใช้งานจริง ถือสินค้า ถ่ายกล้องมือถือ แสงธรรมชาติ
   - ✨ **สตูดิโอมินิมอล พรีเมียม**: แท่นวางมินิมอล แสงนวล สไตล์เกาหลี คลีนตา เหมาะกับสกินแคร์/เครื่องสำอาง
   - 🎯 **สาธิตแก้ปัญหาจริง (Problem-Solver)**: เน้นผลลัพธ์ Before/After สินค้าแก้ปัญหาชีวิตประจำวัน
   - 🎤 **ไลฟ์สดสไตล์แม่ค้า (TikTok Live Vibe)**: บรรยากาศห้องไลฟ์สด ไฟสตูดิโอ แม่ค้าถือสินค้าพร้อมปักตะกร้า

3. **ลำดับการสร้างสินค้าแบบมืออาชีพ (Image ➜ Video Pipeline)**:
   - สั่ง AI สร้างภาพถ่ายสินค้าจริงในอัตราส่วน **9:16** ก่อน
   - นำภาพที่ได้มาสร้างความเคลื่อนไหว (Video Animation) 720p / 9:16 ด้วย Google Flow (Veo 3.1) หรือ Meta AI

4. **เชื่อมต่อ DeepSeek API (Model: `deepseek-chat`)**:
   - ใช้โมเดลที่คุ้มค่าที่สุด (~$0.14 ต่อ 1 ล้านโทเค็น)
   - เจน Prompt สร้างภาพ, คำสั่งขยับวิดีโอ, และแคปชั่นภาษาไทยพร้อมแฮชแท็กกระตุ้นให้กดตะกร้าเหลือง

5. **ระบบคิวและกำหนดรอบ (Scheduler & Loops)**:
   - กำหนดจำนวนรอบที่ต้องการสร้าง (เช่น 1, 3, 5, 10 รอบ)
   - มีระบบดาวน์โหลดคลิปและภาพเก็บลงเครื่องในโฟลเดอร์ `TikTok-Studio-Videos/` อัตโนมัติ
   - โหมดสลับ: สร้างคลิปอย่างเดียว หรือ ส่งเข้า TikTok Studio อัปโหลดและปักตะกร้า

## 🚀 วิธีติดตั้งส่วนขยายเข้า Google Chrome

1. เปิดเบราว์เซอร์ Google Chrome ไปที่หน้า:
   ```text
   chrome://extensions
   ```
2. เปิดสวิตช์ **โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)** ที่มุมขวาบน
3. คลิกปุ่ม **โหลดส่วนขยายที่คลายการบีบอัดแล้ว (Load unpacked)**
4. เลือกโฟลเดอร์:
   ```text
   C:\Users\USER\.gemini\antigravity\scratch\flow-tiktok-studio\dist
   ```
5. ส่วนขยาย **TikTok AI Studio** จะปรากฏขึ้นในแถบ Extensions ให้กดปักหมุด (Pin) ไว้เพื่อเปิดใช้งานเป็น Side Panel แผงด้านข้างได้ทันที!
